
 AI Interview Simulator
 
Project Overview:
The AI Interview Simulator is a web-based application developed using Python and Streamlit to help students practice technical interviews. The platform allows users to upload their resume, enter a job description, and participate in a simulated interview. The system dynamically adjusts question difficulty based on user performance and generates a final evaluation report.

Technologies Used:
Python
Streamlit
Session State Management
File Upload Handling
Interactive UI Components

Key Features:
User authentication and login system
Resume upload functionality
Job description input
Adaptive interview difficulty levels
Real-time scoring system
Performance evaluation and feedback
Progress tracking during interviews
Final interview report with strengths and improvement areas
